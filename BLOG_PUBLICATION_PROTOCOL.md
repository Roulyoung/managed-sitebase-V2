# Blog Publication Protocol

Use this when a blog post is created, rewritten, localized, or prepared for publish.

## Goal

Publish content that is:

- search-friendly
- readable in every target language
- factually correct
- consistent with brand voice
- free of obvious machine-translation artifacts

## Required Workflow

1. Write the English master first.
2. Review the English version by hand.
3. Localize in context, not word-for-word.
4. Check SEO in every language.
5. Run a manual QA pass before publish.
6. Create a private preview if approval is needed.
7. Publish only after final sign-off.

## Quality Checks

- title matches the search intent
- meta description is concise and clickable
- slug strategy is intentional
- headings support the page goal
- internal links are correct
- no mixed-language leftovers unless intentional
- rendered output is clean on mobile and desktop

## Translation Notes

- preserve intent and conversion logic
- adapt phrasing to local search behavior
- keep legal, medical, and compliance claims accurate
- avoid literal translations that sound unnatural
