# Project Notes

Use this file for short-lived but important implementation notes.

## Record

- date
- repo or project name
- task summary
- decision made
- follow-up needed
- rollback note if relevant

## Good Uses

- temporary exceptions
- known limitations
- migration steps
- content or SEO decisions that affect future cloning
- worker routing notes

## Avoid

- raw secrets
- client-only brainstorming that does not affect template reuse
- long logs that belong in the session transcript
