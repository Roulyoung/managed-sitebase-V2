# Read First

Start here when opening this project.

This repo is managed-sitebase-V2.

## What This Means

- For worker, checkout, deploy, Sheets, Stripe, or cross-project changes, do not skip the docs.
- If the user does not mention the right file, use the failsafe order above.
- If a breakage happened after a known-good date, roll back to the last known-good snapshot first.
- Before editing a shared backend or deploy target, run `WORKER_SAFETY_PRECHECK.md`.
- Check `PROJECT_CONTEXT.md` if you are unsure whether you are in the right repo.
